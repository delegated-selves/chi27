# Delegated Selves - CHI 2027 Workshop Website

Static website for the CHI 2027 workshop "Delegated Selves: Privacy, Security, and Identity for AI Agents in Social Environments".

## Recommended GitHub Pages setup

Repository name:

```text
delegated-selves/chi27
```

The site is published from the `gh-pages` branch, which gives this GitHub Pages URL:

```text
https://delegated-selves.github.io/chi27/
```

If the workshop later gets a custom domain, good candidates are:

```text
delegated-selves.org
delegated-selves-workshop.org
chi27-delegated-selves.org
```

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Source material

The website copy is adapted from the draft workshop proposal PDF. Placeholder items in the draft have been converted to "to be announced" language for public-facing use.
